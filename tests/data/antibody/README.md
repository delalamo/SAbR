# Antibody structure test fixtures

These fixtures support the independent numbering, coordinate invariance,
multidomain, and structural-gap regression tests. They were moved unchanged
from the former benchmarks/antibody directory.

The nine PDB chain files contain deposited N/CA/C coordinates. Seven CSV files
provide independent SAbDab IMGT annotations; ubiquitin and lysozyme are negative
controls without antibody labels. Two terminal-truncation cases reuse 12E8 H.

The manifest preserves source URLs, retrieval metadata, coordinate and label
SHA-256 hashes, and SAbDab identifiers. SAbDab annotations are CC BY 4.0.
Numbering labels were mapped through deposited mmCIF label_seq_id and author
residue IDs, not generated by SAbR. Training-set overlap has not been audited;
these fixtures are regression checks, not a held-out accuracy estimate.

The test helpers in tests/antibody_cases.py load these files without network
access. Run pytest tests/test_antibody_structures.py to check provenance,
label agreement, boundaries, and invariance. The standalone benchmark runner,
curation program, and saved reports have been removed.
